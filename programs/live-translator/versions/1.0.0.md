# Live Translator 1.0.0

**Fecha · Date:** 2026-11-13
**Descarga · Download:** [LiveTranslator-Setup-1.0.0.exe](https://github.com/pancracio-studios/pancraciostudios-projects/releases/download/live-translator-v1.0.0/LiveTranslator-Setup-1.0.0.exe)
**Requisitos · Requirements:** Windows 10 (2004+) / 11, 64 bits

## Novedades

Primera versión pública.

- **Vista espejo** en la pantalla que elijas, con el texto traducido en su posición original.
- **Overlay** de una sola pantalla: no recibe clics, no se lee a sí mismo y muestra el original al pasar el mouse.
- **Fuentes**: pantalla completa, ventana o región dibujada con el mouse.
- **OCR de Windows** con instalación del paquete de idioma desde la app; **RapidOCR** opcional.
- **Traducción**: automática gratuita con respaldo entre servicios, DeepL (clave gratuita) y Argos (sin internet).
- **Pensado para juegos**: espera a que el texto termine de escribirse, oculta traducciones viejas y guarda una caché.
- **Atajos globales**: `Ctrl+Alt+T`, `Ctrl+Alt+P`, `Ctrl+Alt+R`, `Ctrl+Alt+O`.
- **Instalador** por usuario (sin administrador), con accesos directos y desinstalador.

## What's new

First public release: mirror view on any screen, single-screen overlay, full screen / window / region sources,
Windows OCR with in-app language install, free auto translation with fallback, DeepL and offline Argos,
game-friendly detection, global shortcuts and a per-user installer.
