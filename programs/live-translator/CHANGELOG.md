# Historial de cambios · Changelog

## [1.0.0] — 2026-11-13

Primera versión pública · First public release. [Notas completas](versions/1.0.0.md)

- Vista espejo en cualquier pantalla y overlay de una sola pantalla.
- Fuente: pantalla completa, ventana o región.
- OCR de Windows (con instalación de idiomas desde la app) y RapidOCR opcional.
- Traducción gratuita automática con respaldo entre servicios, DeepL y Argos.
- Caché de traducciones, espera a texto quieto y ocultado de traducciones viejas.
- Atajos globales e instalador para Windows.
