# User guide · Live Translator

> The app's interface is in Spanish for now. This guide maps each option to English.

## Install

1. Download **`LiveTranslator-Setup-1.0.0.exe`** from [Releases](https://github.com/pancracio-studios/pancraciostudios-projects/releases).
2. Run it. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway** (the installer isn't signed with a paid certificate).
3. Pick the installer language, accept the terms and optionally add a desktop shortcut.

No admin rights needed: it installs for your user in `%LOCALAPPDATA%\Programs\Live Translator` and appears in the Start menu under **Pancracio Studios**.

## Quick start

| Panel (Spanish) | Meaning |
|---|---|
| **Qué traducir → Fuente** | What to translate: *Pantalla completa* (full screen), *Una ventana* (a window), *Una región* (a region you drag) |
| **Idiomas: De … a …** | From … to … (*Detectar automático* = auto-detect) |
| **Vista espejo en otra pantalla** | Mirror view on another screen |
| **Overlay encima del original** | Overlay on top of the original (single screen) |
| **Estilo** | *Cubrir el texto original* (cover the original text) or *Panel oscuro* (dark panel) |
| **Ver el original al pasar el mouse** | Hover to reveal the original |
| **Traductor** | Translator: *Automático gratis* (free, recommended), Google, Microsoft, DeepL (API key), Argos (offline) |
| **Lector (OCR)** | Text reader: Windows OCR (recommended) or RapidOCR |
| **Ampliar al leer** | Upscale before reading (use ×2/×3 for tiny or pixel text) |
| **Esperar texto quieto** | Wait for typewriter-style dialogue to finish |
| **Iniciar / Detener** | Start / Stop |

## Shortcuts

`Ctrl+Alt+T` show/hide translations · `Ctrl+Alt+P` pause · `Ctrl+Alt+R` re-read · `Ctrl+Alt+O` toggle overlay.
Mirror view: `F11` fullscreen · `H` show original · `Space` pause.

## Tips

- Run games in **borderless window** mode.
- For Japanese, Chinese, Korean, etc., choose the exact source language; the app offers to install Windows' OCR pack for it.
- Data folder: `%APPDATA%\PancracioStudios\LiveTranslator` (settings, cache, `log.txt`).
- Uninstall from **Settings → Apps → Live Translator**.
